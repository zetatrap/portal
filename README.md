# La Orden Crew - Sello Musical Futurista

Web oficial de La Orden Crew, sello musical con diseño futurista y temática espacial.

## 🚀 Tecnologías

- **React 18** con TypeScript
- **Vite** - Build tool ultrarrápido
- **Tailwind CSS** - Estilos modernos y responsivos
- **Framer Motion** - Animaciones profesionales
- **React Router** - Navegación SPA
- **Lucide React** - Iconos modernos

## ✨ Características

- 🌌 Diseño espacial futurista con efectos de estrellas animadas
- 🎨 Paleta de colores: Negro profundo con acentos en rojo carmesí
- ⚡ Animaciones suaves y profesionales
- 📱 100% Responsive
- 🛍️ Tienda con sistema de filtros (Beats, Apps, Videos, Webs)
- 📝 Formulario de registro interactivo
- 🎵 Sección de presentación de la discográfica

## 🛠️ Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar servidor de desarrollo
npm run dev

# Build de producción
npm run build

# Preview de producción
npm run preview
```
